# IPO_Anthropic

Ce projet à pour but de suivre le processus de valorisation durant l'IPO de l'entreprise Anthropic, de sa stratégie par rapport aux classes d'actions qu'elle émet et les placements privée des fournisseurs d'Anthropic au sein de cette IPO ainsi que leurs objectifs. 

C'est pourquoi j'essayerai de répondre à ces deux questions générales :

- Pourquoi tant de classes d'actions ? Quelle est leurs utilités à chacunes ?
- Pourquoi ce placement privé auprès des fournisseurs ?
